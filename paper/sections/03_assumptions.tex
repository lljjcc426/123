\section{模型假设}

结合题目条件和字段边界，作如下假设。

\begin{enumerate}[label=\textbf{A\arabic*.}]
  \item 每台设备在任一5分钟时隙内至多执行一个项目；一个项目执行期间连续占用同一台设备和一名医生，不允许中断。该假设对应超声检查的基本互斥资源特征。
  \item 仿真日历采用每日$8{:}00$--$12{:}00$、$13{:}00$--$17{:}00$两个标准日班工作块，项目不跨午休或日界。该时窗是根据表6训练期首末报告活动重建的可复现容量模板，不是A医院未来正式班表；医院实施时应直接换入当日班表。
  \item 同一患者的多个项目必须串行完成；若相邻项目更换房间，主情景预留10分钟转运和重新准备时间，并用5与15分钟检验边界。附件没有院内转运用时，因而10分钟不被写成医院事实。同一房间可连续衔接，转运时间为0。题目“通常安排在同一时段、同一诊室”被表达为优先规则而非绝对硬约束，因为部分项目没有共同兼容设备。
  \item 项目服务时长采用题给区间中点作为名义时长，并向上取整到5分钟；固定随机种子在评价期和预热期分别抽取最接近5\%的整数个事件作为特殊病例，其全部项目采用题给上界。多项目患者仍逐项累计时长而不并行重叠：附件没有给出同次检查的固定节约比例，且同一设备和医生不能同时完成两个项目。该处理不虚构额外倍率或合并收益。
  \item 空腹项目必须在当天10时前完成；憋尿事件主情景按“开单时刻后60分钟准备完成”计算，45和90分钟用于边界分析。门诊/体检若在计划日开始前已经完成该提前量，可从日工作块起点进入排程，不再机械追加60分钟。该值不来自本题附件；国内医院公开超声流程中存在“提前1小时喝水憋尿”的临床准备说明\cite{hrhospital2025}，但A医院上线时仍应读取患者实际准备完成时刻。床旁项目只在7号机安排。
  \item 门诊和体检的报告日期作为回顾性计划日压力场景。该假设用于检验“若当日需求需在当日完成，资源是否可行”，不等同于拥有真实预约记录。
  \item 未排入截止窗口的事件保留为未分配，并进入指标分母；不把这些患者从等待分布和完成率中删除。等待分位数只对成功排入者计算，同时单列未分配人数，以免条件分位数掩盖失败患者。
  \item 设备购置日期和型号不用于扩大项目能力集合。设备能否执行项目首先由表1文本证据决定；同刻候选仍并列时，程序只用累计负荷、训练期稀缺权重和设备编号作确定性择优。
\end{enumerate}
