# 正式论文交付说明

## 正式文件

- `main.tex`：模块化 LaTeX 总入口。
- `sections/`：摘要之后的一至九章和附录。
- `tables/`：正文引用的最终三线表。
- `超声预约优化论文.pdf`：XeLaTeX 正式提交稿。
- `build_latex.py`：两遍 XeLaTeX 构建入口。

不提供 Word 版论文。工作区根目录的 `C题：超声预约优化问题.docx` 是赛题原文，不是论文成品。

## 构建

从工作区根目录运行：

```powershell
python paper/build_latex.py
```

版面为 A4，四边页边距2.5cm，无页眉，页脚居中连续页码；中文正文宋体，西文和数字 Times New Roman，表格为三线表，无目录。

## 页数口径

当前正式 PDF 共145页：

- 摘要至“八、模型改进与推广”：第1--27页，共27页，计入正文上限；
- “九、参考文献”：第28--29页，共2页，不计入正文；
- 附录A--I：第30--145页，共116页，不计入正文。

正文低于30页上限，参考文献和附录没有混入正文页数。最终审核见工作区根目录三个审核报告和 `../qa/FINAL_QA_REPORT.md`。
