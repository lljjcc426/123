# 正式论文交付说明

## 正式文件

- `main.tex`：模块化 LaTeX 总入口，是唯一正式主稿。
- `sections/`：摘要之后的一至九章和附录入口。
- `tables/`：正文引用的最终数据表。
- `超声预约优化论文.pdf`：XeLaTeX 正式提交稿。
- `build_latex.py`：正式构建入口。

本项目不提供 Word 版论文。工作区根目录的 `C题：超声预约优化问题.docx` 是赛题原文，
不是生成的论文成品。

## 构建

从工作区根目录运行：

    python paper/build_latex.py

脚本调用 XeLaTeX 两遍，生成并复制中文文件名的正式 PDF；成功后自动清理
`main.aux`、`main.log`、`main.out` 和临时 `main.pdf`。版面为 A4，中文正文宋体，
西文 Times New Roman，标题黑体，无页眉，页脚居中页码。

论文中的数据表和图形应先由 `supporting_materials/README.md` 所列唯一复现链生成，
不能从旧模型目录或人工改写数字。

## 页数口径

当前正式 PDF 共 114 页：

- 摘要至“八、模型改进与推广”：第 1--21 页，共 21 页，计入正文上限；
- “九、参考文献”：第 22--23 页，共 2 页，不计入正文；
- 附录 A--J：第 24--114 页，共 91 页，不计入正文。

因此正文没有用附录压缩凑页，也没有把参考文献或程序附录误计入 30 页正文上限。
最终审计记录见 `../qa/FINAL_QA_REPORT.md`。
